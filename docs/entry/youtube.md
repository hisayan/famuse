## Title
famuse — When Muse Joins Your Family (Meta AI Hackathon Demo)

## Description

Muse doesn't visit your family. It joins it.

famuse (family + Muse, made for family use) is an open-source private family
hub where Muse Spark lives inside the conversation as @famuse — an AI butler
for dinner ideas, pet care, catch-ups, and everything in between.

Try the live demo: https://famuse.a10n.workers.dev
Source code (MIT): https://github.com/hisayan/famuse

Built for the Meta Global AI Developer Hackathon — Indie track, Build for
Your World.
- Muse Spark via the Meta Model API powers @famuse
- Cloudflare Workers + Durable Objects + D1 + R2, one-command deploy to your
  own account
- Your photos and messages stay in infrastructure you control
